# DFIR Workflows

A public library of documented digital forensics and incident response workflows for authorized investigations.

## Scope

This repository is intended for reusable procedures, checklists, and documentation. It contains no case data. Adapt each workflow to the applicable authorization, policy, and legal requirements before use.

## Workflow lifecycle

1. Define authorization, scope, roles, and handling requirements.
2. Preserve the source and document custody and actions.
3. Acquire evidence using appropriate, validated methods.
4. Analyze working copies and record tools, versions, and observations.
5. Review findings and prepare a clear, traceable report.

## Planned content

- Intake and scope checklist
- Evidence handling and documentation templates
- Acquisition and verification notes
- Analysis and reporting checklists

This is an initial scaffold; project-specific procedures will be added as they are prepared and reviewed. Do not submit personal data, client information, credentials, or confidential case material.

## Contributions

Proposals for general, reusable, and authorized workflows are welcome. Include scope, assumptions, prerequisites, and limitations with each contribution.
